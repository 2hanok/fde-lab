# 데이터 규칙 (운동 루틴)

## 1. 칸
| 칸 이름 | 형식 | 필수 |
|---|---|---|
| 요일 | 월·화·수·목·금·토·일 중 한 글자 | 필수 |
| 부위 | 상체·하체·어깨·등·전신·유산소 중 하나 | 필수 |
| 목표 | 감량·근력·스트레칭 중 하나 | 필수 |
| 기구 | 센터 기구 이름(예: 트레드밀, 덤벨, 매트) | 필수 |

## 2. 중복
- 요일과 기구가 같으면 같은 루틴으로 봅니다.
- 비교하기 전에 앞뒤 공백을 지우고 영문은 소문자로 맞춥니다.
- 중복이면 먼저 적힌 줄을 남깁니다.

## 3. 정렬
- 1차: 요일 순(월→일), 2차: 부위 순(상체→하체→어깨→등→전신→유산소)
- 값이 같거나 비어 있으면 파일에 적힌 순서를 따릅니다.

## 4. 제외
- 필수 칸이 비어 있으면 뺍니다.
- 칸 형식이 틀리면 뺍니다(예: 요일이 «화요일»로 적힘).
- 뺀 줄은 이유와 함께 화면에 보여 줍니다.
